# Дипломный проект "Мобильный хоспис"

## Автотесты для мобильного приложения

### Требования для запуска
- Android Studio Hedgehog или новее
- JDK 11
- Эмулятор Android API 33+ или физическое устройство

### Запуск автотестов
1. Открыть проект в Android Studio
2. Запустить эмулятор
3. Нажать правой кнопкой на `tests` → `Run 'All Tests'`

### Структура проекта
- `pages/` — Page Object классы
- `tests/` — Тестовые классы
- `data/` — Тестовые данные
- `utils/` — Утилиты (IdlingResource)
