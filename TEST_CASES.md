# Тест-кейсы для приложения "Мобильный хоспис"

## TC-01: Успешная авторизация
| Параметр | Значение |
|----------|----------|
| Предусловие | Приложение запущено, экран авторизации |
| Шаги | 1. Ввести логин "login2"<br>2. Ввести пароль "password2"<br>3. Нажать "Sign in" |
| Ожидаемый результат | Открывается главный экран |

## TC-02: Авторизация с неверным паролем
| Параметр | Значение |
|----------|----------|
| Предусловие | Приложение запущено, экран авторизации |
| Шаги | 1. Ввести логин "login2"<br>2. Ввести пароль "wrong123"<br>3. Нажать "Sign in" |
| Ожидаемый результат | Сообщение об ошибке "Wrong login or password" |

## TC-03: Переход в About и возврат
| Параметр | Значение |
|----------|----------|
| Предусловие | Авторизация выполнена |
| Шаги | 1. Нажать кнопку меню (☰)<br>2. Выбрать "About"<br>3. Нажать кнопку "Назад" |
| Ожидаемый результат | Возврат на главный экран |

## TC-04: Выход из аккаунта
| Параметр | Значение |
|----------|----------|
| Предусловие | Авторизация выполнена |
| Шаги | 1. Нажать кнопку меню (☰)<br>2. Выбрать "Log out" |
| Ожидаемый результат | Возврат на экран авторизации |

## TC-05: Открытие цитат (Our Mission)
| Параметр | Значение |
|----------|----------|
| Предусловие | Авторизация выполнена |
| Шаги | 1. Нажать кнопку "Our Mission" (⭐)<br>2. Кликнуть по любой цитате |
| Ожидаемый результат | Цитата раскрывается/скрывается |

## TC-06: Клик по новости
| Параметр | Значение |
|----------|----------|
| Предусловие | Авторизация выполнена, есть новости |
| Шаги | 1. Нажать на любую новость в списке |
| Ожидаемый результат | Открывается полный текст новости |

## TC-07: Создание новой новости
| Параметр | Значение |
|----------|----------|
| Предусловие | Авторизация выполнена |
| Шаги | 1. На главном экране нажать кнопку редактирования новостей (карандаш ✏️)<br>2. Нажать кнопку "+" (добавить новость)<br>3. Заполнить поля: заголовок, описание, дату публикации<br>4. Выбрать категорию новости<br>5. Нажать кнопку "Save" |
| Ожидаемый результат | Новая новость появилась в списке новостей |

## TC-08: Редактирование существующей новости
| Параметр | Значение |
|----------|----------|
| Предусловие | Авторизация выполнена, есть хотя бы одна новость |
| Шаги | 1. Нажать кнопку редактирования новостей (карандаш ✏️)<br>2. Выбрать новость для редактирования<br>3. Изменить заголовок или описание<br>4. Нажать "Save" |
| Ожидаемый результат | Текст новости изменился, изменения отображаются в списке |

## TC-09: Удаление новости
| Параметр | Значение |
|----------|----------|
| Предусловие | Авторизация выполнена, есть хотя бы одна новость |
| Шаги | 1. Нажать кнопку редактирования новостей (карандаш ✏️)<br>2. Выбрать новость для удаления<br>3. Нажать на иконку корзины 🗑️<br>4. Подтвердить удаление |
| Ожидаемый результат | Новость исчезла из списка новостей |

## TC-10: Отмена удаления новости
| Параметр | Значение |
|----------|----------|
| Предусловие | Авторизация выполнена, есть хотя бы одна новость |
| Шаги | 1. Нажать кнопку редактирования новостей (карандаш ✏️)<br>2. Выбрать новость для удаления<br>3. Нажать на иконку корзины 🗑️<br>4. Нажать "Отмена" |
| Ожидаемый результат | Новость осталась в списке новостей |

## TC-11: Фильтрация новостей по категории
| Параметр | Значение |
|----------|----------|
| Предусловие | Авторизация выполнена, есть новости разных категорий |
| Шаги | 1. Нажать кнопку фильтра (воронка 📊)<br>2. Выбрать категорию новостей<br>3. Нажать "Apply" или "ОК" |
| Ожидаемый результат | Отображаются только новости выбранной категории |

## TC-12: Сортировка новостей по дате
| Параметр | Значение |
|----------|----------|
| Предусловие | Авторизация выполнена |
| Шаги | 1. Нажать кнопку сортировки (⇅)<br>2. Выбрать сортировку по дате (по возрастанию/убыванию) |
| Ожидаемый результат | Порядок новостей изменился в соответствии с выбранной сортировкой |
