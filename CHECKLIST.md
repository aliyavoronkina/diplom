# Чек-лист тестирования приложения "Мобильный хоспис"

## 1. Авторизация
- [ ] Вход с валидным логином (login2) и паролем (password2)
- [ ] Вход с невалидным логином
- [ ] Вход с невалидным паролем
- [ ] Вход с пустыми полями
- [ ] Вход только с логином (без пароля)
- [ ] Вход только с паролем (без логина)
- [ ] Отображение ошибки при неверных данных
- [ ] Скрытие/показ пароля (глазик)

## 2. Главный экран (после авторизации)
- [ ] Отображение кнопки меню (☰) в левом верхнем углу
- [ ] Отображение кнопки "Authorization" (🔑)
- [ ] Отображение кнопки "Our Mission" (⭐)
- [ ] Отображение блока с новостями
- [ ] Возможность развернуть/свернуть список новостей
- [ ] Каждая новость кликабельна

## 3. Меню (клик по ☰)
- [ ] Открывается меню с пунктами
- [ ] Пункт "About" ведет на экран About
- [ ] Пункт "Log out" выходит из аккаунта
- [ ] Закрытие меню по клику вне его

## 4. About (О приложении)
- [ ] Отображается информация о приложении
- [ ] Кнопка "Назад" (стрелка) работает
- [ ] Вернуться на главный экран

## 5. Our Mission (Цитаты)
- [ ] Открывается экран с цитатами
- [ ] Список цитат отображается
- [ ] Клик по цитате раскрывает/скрывает текст
- [ ] Кнопка "Назад" работает

## 6. Authorization (выйти/войти заново)
- [ ] Клик по кнопке Authorization открывает меню с "Log out"
- [ ] После выхода возврат на экран авторизации

## 7. Новости
- [ ] Список новостей загружается
- [ ] Можно отфильтровать новости по дате
- [ ] Клик по новости открывает подробности
- [ ] Можно создать новую новость (есть права)
- [ ] Можно редактировать новость
- [ ] Можно удалить новость

## 8. UI/UX проверки
- [ ] Приложение не крашится при нестандартных действиях
- [ ] Поворот экрана не ломает отображение
- [ ] Приложение корректно сворачивается/разворачивается
